# Amazon Sales Data Analysis (EDA)

## Objective
To analyze customer purchasing behavior and category-wise sales trends.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Key Insights
- Majority transactions fall between ₹500–₹1000
- High-value outliers impact revenue analysis
- T-shirts and Shirts dominate order volume
- Sales are concentrated in limited categories

## Skills Demonstrated
Data Cleaning | Data Visualization | Business Insight Extraction
